# [개발 계획서] 프로젝트 등록 SEO 고도화 & UI/UX 개선안

## 1. 개요 및 비즈니스 목표

- **목적**: 관리자가 시공사례 등록 시 클릭 몇 번으로 고품질의 SEO 친화적 데이터를 생성하고, 모바일 오퍼레이션의 효율성을 극대화합니다.
- **주요 전략**:
  - 지역(대구/경산) 및 품목 조합 키워드로 개별 페이지가 검색엔진에 자연스럽게 노출되도록 메타데이터를 고도화합니다.
  - 모바일 터치 오작동을 차단하고 입력을 단순화하는 1단 콤팩트 UI 구조를 설계합니다.
  - 반복적인 설명 작성 피로도를 낮추기 위한 백그라운드 AI 본문 생성 서비스를 도입합니다.
  - **멀티모달 이미지 분석 도입**: 단순 텍스트 입력값에 의존하지 않고, 실제 업로드된 시공 사진을 AI가 분석하여 생동감 넘치는 설명글과 최적의 추천 제목을 자동으로 도출합니다.
  - **[신규] AI 서비스 추상화 (Repository 및 Provider 패턴 적용)**: OpenAI, Google Gemini 등 AI 제공 엔진의 스펙 변경이나 요금 정책에 유연하게 대응할 수 있도록 AI 생성 로직을 인터페이스로 추상화하고, 환경변수 설정에 따라 최적의 AI 엔진(Gemini 무료 티어 우선)으로 자동 전환되도록 구현합니다.

## 2. 데이터베이스 스키마 및 마이그레이션 명세

- **스키마 변경 사항**:

  | 컬럼명          | 기존 타입     | 변경 타입       | 설명 / 비고                                        |
  | :-------------- | :------------ | :-------------- | :------------------------------------------------- |
  | `category`      | `text` (단일) | (삭제 예정)     | 기존 단일 카테고리 보관용 컬럼                     |
  | `categories`    | -             | `text[]` (다중) | Supabase Array 타입으로 복수 카테고리 보존         |
  | `region`        | -             | `text`          | 시/구 및 동/리를 조합하여 저장 (예: "경산 가일리") |
  | `building_type` | -             | `text`          | 건물 유형 (단독주택, 아파트, 빌라, 상가 등)        |
  | `status`        | -             | `text`          | 프로젝트의 활성/삭제 상태 (`active` / `deleted`)   |

- **데이터 마이그레이션 이행 규칙**:
  - 기존 단일 `category`를 배열 `categories`로 안전하게 컨버팅하는 SQL 스크립트를 작성하여 반영합니다.
  - 기존 주소 데이터 파싱 시 `경산시`, `대구광역시` 등의 행정구역 공식 명칭을 `경산`, `대구`와 같은 검색 축약형 명칭으로 정규식을 이용해 하위 호환 매핑을 수행합니다.

## 3. 사용자 경험(UX) 및 폼 UI 설계

- **5단계 인터랙티브 AI 마법사 (Wizard Flow)**:
  - 입력 화면을 5단계(`사진 등록 ➔ 시공 위치 ➔ 건물/품목 ➔ 자재스펙 ➔ AI 완성`)로 나누어 모바일 및 데스크톱 입력 스트레스를 획기적으로 낮췄습니다.
  - **History API (popstate) 브라우저 뒤로가기 제어**: 사용자가 브라우저 뒤로가기나 스와이프 백을 했을 때, 작성 중인 폼을 완전히 나가는 대신 이전 단계(Step)로만 한 칸씩 뒤로 가도록 UX를 최적화했습니다. (1단계 상태에서 뒤로갈 때만 관리 목록 페이지로 안전 퇴장)
  - **AI 생성 시 조작 원천 차단 (Dim Overlay)**: AI 추천 기능이 구동되어 API가 호출되는 동안 화면 전체에 백드롭 블러 딤 오버레이를 씌워 관리자의 추가 조작이나 스텝 이동 시도를 완벽히 차단하고 정합성을 지켜줍니다.
- **위치 기반 동네 추천 퀵 칩 및 기타 지역 지원**:
  - 시공 도시(대구/경산) 선택 시 하단에 실제 시공이 많은 대표 7대 동네 퀵 칩이 나타나며, 탭하면 상세 주소란에 즉시 반영됩니다.
  - 대구/경산 외의 영천, 부산, 칠곡 등 **`기타 지역`** 옵션을 제공하여 주소 자동조합기가 방해하지 않고 전체 지역명을 자유롭게 수동 기재(예시: 영천 금호읍, 부산 해운대구, 칠곡 왜관읍) 및 파싱할 수 있도록 지원합니다.
- **실물 사양 퀵 칩 및 실시간 SEO 글자 수 게이지**:
  - 창호 시공 실무를 반영한 11대 스펙 퀵 칩(`KCC 140 발코니단창`, `24mm 로이그린유리`, `외부 실리콘 코킹 마감` 등)을 클릭 몇 번으로 조합할 수 있습니다.
  - 설명 글자 수에 맞춰 실시간으로 차오르는 가로 프로그레스 바를 적용하여, 주황(부족) ➔ 초록(최적) ➔ 빨강(초과) 등의 피드백을 통해 완벽한 SEO 설명문 작성을 유도합니다.
- **프로젝트 목록 카드 갤러리 상단 재배치**:
  - 각 시공사례 카드의 상단에 대표 시공 사진을 필두로 모든 일반 사진들을 가로 스크롤 썸네일 슬라이더로 상단 배치하고, 대표 사진 테두리와 배지를 amber-500 황금색(`★ 대표`)으로 통일하여 시인성과 일관성을 극대화했습니다.

## 4. SEO 및 메타데이터 자동 반영 규칙

- **Title 태그 조합 공식**:
  - `{제목} — {지역} {대표품목} 시공 | 경산창호`
  - _대표 품목 결정 (내부 가중치)_: 다중 카테고리 선택 시 타이틀이 너무 길어져 검색 엔진 노출이 잘리는 것을 방지하기 위해 아래 우선순위에 의거한 **단 1개의 대표 품목**만 타이틀에 반영합니다.
  - _우선순위_: `하이샤시` > `판넬` > `방화문/ABS도어` > `유리` > `방범창` > `방충망` > `잡철/스텐`
  - **AI 추천 제목 활용**: AI가 업로드된 시공 사진을 보고 실제 시공 형태에 가장 잘 부합하는 구체적인 제목 후보(예: "경산 사동 단독주택 화이트 하이샤시 및 방충망 교체 시공")를 자동 제안하며, 관리자는 이 제안 제목을 즉시 사용할 수 있습니다.
- **Meta Description 및 구조화 데이터 매핑**:
  - `meta description`: 자동 생성 description 또는 AI 생성 설명문을 개행 문자(`\n`)가 보존된 채로 매핑하며, 상세 페이지 렌더링 시 `whitespace-pre-wrap` 스타일을 부여합니다.
  - `JSON-LD address`: `region` 값을 `addressLocality`에 매핑하여 지역 기반 SEO를 극대화합니다.
  - `JSON-LD Service`: 복수 선택된 `categories` 배열을 `itemListElement`에 루프 매핑하여 검색 로봇의 인덱싱 품질을 높입니다.
- **사용자 화면 필터**:
  - 사용자용 갤러리 필터는 직관성 확보와 `No Results` 발생 예방을 위해 기존 단일 선택을 그대로 유지합니다.
  - DB의 `categories` 배열에서 교집합 조회를 수행하기 위해 Supabase JS 클라이언트의 `.contains()` 연산자를 사용합니다.

## 5. [신규] AI 서비스 추상화 및 팩토리 패턴 설계

프로젝트 내 Repository 패턴 구성과 동일하게, 외부 AI API의 연동 로직을 추상화하여 결합도를 낮추고 모의 테스트 및 동적 교체가 쉽도록 설계합니다.

### 5-1. AI 서비스 인터페이스 (`AiService`)

```ts
export interface AiResponse {
  success: boolean;
  description: string;
  suggestedTitle: string;
  isFallback: boolean;
}

export interface AiService {
  generateDescription(params: {
    region: string | null;
    buildingType: string | null;
    categories: string[];
    details: string;
    images?: string[]; // base64 또는 URL
  }): Promise<AiResponse>;
}
```

### 5-2. 구현 어댑터 분리

- **`GeminiAiService` (Google Gemini 2.5 Pro)**:
  - 구글 AI Studio 무료 API 키(`GEMINI_API_KEY`)를 기반으로 작동합니다.
  - 하루 50회 완전 무료 호출(2 RPM / 50 RPD) 규격을 사용하며, 시공 사진의 뛰어난 시각적 분석과 화려한 작문력을 무료로 지원합니다.
- **`OpenAiService` (OpenAI GPT-4o-mini)**:
  - OpenAI API 키(`OPENAI_API_KEY`)를 기반으로 작동합니다.
  - JSON Mode(`response_format: { type: "json_object" }`)로 동작하며 멀티모달 이미지 식별을 제공합니다.
- **`FallbackAiService` (Local Rule Engine)**:
  - 로컬 템플릿과 룰 조합 엔진에 기반하여 비용 청구와 네트워크 연결 없이 작동합니다.

### 5-3. 팩토리 및 자동 전환 규칙 (`getAiService()`)

서버 환경변수 설정에 따라 AI 서비스 싱글톤을 자동으로 전환하여 반환합니다.

1. `GEMINI_API_KEY` 환경변수가 존재할 경우: **`GeminiAiService` (권장 - 완전 무료)** 로드.
2. `GEMINI_API_KEY`가 없고 `OPENAI_API_KEY`가 존재할 경우: **`OpenAiService`** 로드.
3. API 키가 전부 미지정되었거나 호출 오류(한도 초과 등) 시: **`FallbackAiService`** 로 자동 fallback 복원.

### 5-4. 동적 모델명 설정 (Dynamic Model Config)

소스코드 수정과 재배포 없이 최신 인공지능 모델로 업그레이드할 수 있도록 모델 세팅을 환경변수로 동적 바인딩합니다.

- **`GEMINI_MODEL`**: 지정하지 않을 시 고성능 Pro 라인업인 `gemini-2.5-pro`가 기본 적용되며, 필요에 따라 `gemini-1.5-flash`나 `gemini-2.0-flash` 등으로 배포 없이 자유롭게 동적 전환이 가능합니다.
- **`OPENAI_MODEL`**: 지정하지 않을 시 `gpt-4o-mini`가 기본 적용됩니다.

- ~~지역 입력 시 공식 명칭('경산시', '대구광역시') 저장~~ → 실제 로컬 검색 키워드 매칭률과 모바일 UI 레이아웃의 효율 극대화를 위해 '경산', '대구'와 같은 축약형 명칭으로 최종 통일합니다.
- ~~Supabase Array 매칭을 위해 `.cs()` 연산자 제안~~ → Supabase JS SDK 호환성과 강력한 타입 세이프티를 보장하기 위해 `.contains()` 연산자로 우회 변경하여 이식했습니다.
- ~~OpenAI 단일 호출 엔진 도입~~ → 구글 AI Studio의 완전 무상 한도 내에서 초고화질 이미지 분석과 고품질의 Copywriting을 무료로 누리기 위해 **Gemini 2.5 Pro를 메인 엔진**으로 채택하고, 제공 엔진 구조를 추상화(인터페이스/어댑터)하여 팩토리화하는 레포지토리 패턴 형식을 차용했습니다.
- **[추가] ~~1단 세로 콤팩트 입력 폼~~ ➔ 5단계 인터랙티브 AI 마법사(Wizard Flow)**: 긴 페이지 양식의 스크롤 및 입력 피로도를 해결하기 위해, 한 화면씩 탭하여 작성하고 popstate 브라우저 뒤로가기와 연동되는 앱 스타일의 스텝 마법사 흐름을 최종 도입합니다.
- **[추가] ~~물리적 프로젝트 삭제 정책~~ ➔ 소프트 삭제(Soft Delete) 정책**: 실수 방지 및 데이터 유실 차단을 위해 Supabase 및 Mock Repository에서 projects 삭제 명령을 `status = 'deleted'` 상태 수정 처리로 전환합니다.
- **[추가] ~~대구/경산으로 제한된 시공 지역 설정~~ ➔ '기타 지역' 확장 및 placeholder 예시 리얼화**: 영천, 부산, 칠곡 등 기타 로컬 지역의 창호 시공도 자유롭게 수동 등록(예시: 영천 금호읍, 부산 해운대구, 칠곡 왜관읍) 및 수정할 수 있도록 유연한 파싱 체계를 확보합니다.
